# Code of Conduct

ScanMate uses the Contributor Covenant Code of Conduct, version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on technical tradeoffs and user outcomes.
- Assume people are using different scanners, servers, and household workflows.

## Unacceptable behavior

- Harassment, intimidation, or discriminatory language.
- Personal attacks.
- Publishing private information without permission.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation when needed to keep the project healthy.
